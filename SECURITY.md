# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub instead: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/zakaria-hamane/HEADROOM/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within a few days, and credit in the fix's release notes if you'd like it.

## Scope

Accounts and sessions (Better Auth), saved plans and share links (Server Actions and their ownership checks), and anything that could expose one user's data to another are in scope. The sizing estimates themselves are not security issues: report those as regular issues.

## Supported versions

Only the latest version on `main` gets security fixes.
